Expanded project brief

Starting from how the model reads Turkish, not just which model to use.

Turkish is agglutinative and morphologically rich: a single root can carry many different meanings and grammatical roles through chained suffixes (ev → evler → evlerimiz → evlerimizden). A tokenizer that treats this structure as arbitrary or purely statistical character spans can under-use the morphological information Turkish carries, which affects context-window efficiency, training token counts, inference cost, and how well word forms are represented internally.

NEDO Turkish Tokenizer's approach is to process Turkish words using root, suffix, and morphological structure rather than frequency statistics alone. Development combined Turkish dictionary resources, morphological segmentation, Turkish suffix structures, vocabulary design, token-efficiency evaluation, and language-model compatibility. The current ruleset accounts for more than 260 Turkish suffix patterns alongside a Turkish-lexicon-informed approach to segmentation.

NEDO's first significant deployment was as the tokenizer behind NEDOQwen 0.8B, where tokenizer scope, model evaluation behavior, and Turkish language-modeling problems were studied together. That experience treated the tokenizer as a directly investigable part of model behavior rather than only a data-preparation utility.

NEDO is designed as the first layer of a longer pipeline for the planned Mercan Turkish model family: tokenizer → pretraining corpus → SFT/reasoning data → training pipeline → Turkish base models trained from scratch. A comparative benchmark against other tokenizers—covering tokenization efficiency, morphological-boundary preservation, tokens-per-word cost, segmentation behavior across Turkish text types, and downstream LLM training impact—is in preparation.

Status: the tokenizer and its morphological ruleset are released as open research. The comprehensive comparative benchmark referenced in the project's public materials is still in preparation and is not yet part of this record.
