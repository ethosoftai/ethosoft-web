Expanded account

A different problem space, another milestone.

EU Code Week Hackathon, run under the European Commission, brought a different competition format and a different problem domain than Ethosoft's earlier hackathons. The process centered on developing an idea quickly and defending it within the hackathon's short timeline.

The result was first place in Türkiye—Ethosoft's first national first-place finish, achieved under a European program rather than a domestic one.
